Welcome to **Donut SMP Market** a simple, fun marketplace experience built around the Donut SMP economy.

This project is designed to work without real life money or email logins. It focuses on fast, easy trading using **Donut SMP money**.

## Key Features

- No email required
- Immediate access to the market
- Uses Donut SMP money as the in-game currency
- Simple buying and selling flow
- Clean, easy-to-understand market interface

## How It Works

1. Open the market interface
2. Browse available items and prices
3. Use Donut SMP money to purchase goods
4. Sell items back into the market to earn money

## Notes

- This project does not implement user authentication
- All market actions are expected to work in a shared session or local mode
- The focus is on the market experience and currency flow
- Be awary that you could get scammed by others
